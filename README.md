EduHub Central - Student Productivity & Learning Dashboard
EduHub Central is a lightweight, all-in-one productivity dashboard designed specifically for students to manage their tasks, maintain intense focus, and keep track of their academic performance. The entire application is natively built within a single file for instantaneous deployment without any complex development overhead.

🚀 Key Features
⏱️ Focus Timer (Pomodoro): An interactive 25-minute study sprint mechanism running with live, real-time interface updates. It helps maximize focus, minimize fatigue, and structure breaks efficiently.

📝 Task & Assignment Planner: A dynamic task board featuring real-time addition, status toggling (🔄 / ✅), deletion, and an intelligent header metric tracking pending assignments.

📊 Quick Grade & GPA Tracker: A customizable course calculator allowing users to add rows for their subjects, assign expected grades, and instantly calculate an estimated Cumulative GPA out of 4.00.

🎨 Responsive UI: Clean styling powered by CSS variables with full responsive layout support for comfortable multi-device viewing.

🛠️ Built With
This project relies completely on core front-end languages and requires zero third-party packages, external tracking scripts, or server frameworks:

HTML5 - Semantic element structure.

CSS3 - Custom variables and modern responsive flexbox/grid layout design.

Vanilla JavaScript - Clean, event-driven state management for data and timers.

📦 Getting Started
Prerequisites
Since this is an independent, client-side application, you don't need any local servers or backend dependencies. All you need is a modern web browser (such as Chrome, Firefox, Edge, or Safari).

Running Locally
Clone this repository to your computer:

Bash


git clone https://github.com/shannuzz/studentdashboard.git
Navigate into your project folder.

Simply double-click the index.html file to launch the workspace directly in your default browser.
